textos

se pueden pintar textos en el canvas utilizando los siguientes metodos:

  • fillText(texto,x,y,[,MaxWidth]) - para textos rellenos
  • strokeText(texto,x,y,[,MaxWidth]) - para textos sin relleno

estilo

para dar estilo a un texto tenemos las siguientes propiedades:

  • font = value - acepta los mismos valores que la propiedad css font
  • textAlign = value - alinea el texto horizontalmente (start,end,left,right o center)
  • textBaseLine = value - alineacion con respecto a la linea base (top,hanging,middle,alphabetic,ideographic,bottom)
  • direction = value - direccion del texto (ltr,rtl,inherit)
  • measureText('texto') - devuelve un objeto TextMetrics que permite obtener los datos de un texto
