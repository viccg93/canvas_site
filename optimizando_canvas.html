Optimizando canvas

Hay una serie de recomendaciones basicas que son de utilidad cuando se trabaja con canvas y permiten mejorar la experiencia y optimizar el uso de recursos

Pre-renderizar objetos primitivos o repetitivos en un canvas offscreen

Se puede dibujar una figura en un canvas (que generalmente se encontrara fuera de la vista) y posteriormente ser llamada como una imagen en el canvas principal 

                
                    myCanvas.offscreenCanvas = document.createElement("canvas");
                    myCanvas.offscreenCanvas.width = myCanvas.width;
                    myCanvas.offscreenCanvas.height = myCanvas.height;

                    myCanvas.getContext("2d").drawImage(myCanvas.offScreenCanvas, 0, 0);

Evitar numeros de punto flotante para cordenadas, es preferible usar enteros

el uso de cordenadas de punto flotante hace que el navegador realice calculos extra para aplicar el efecto anti-aliasing, para evitar dicha sobrecarga se recomienda usar Math.floor() para redondear todas las cordenadas.

No escalar imagenes con el metodo drawImage

Es preferible almacenar varios tamaños de imagen en un canvas offscreen durante la carga en lugar de escalar constantemente con el metodo drawImage()

Usa multiples canvas en capas para escenas complejas

cuando hay escenas u objetos que no cambian, es mejor situarlo en elementos canvas independientes en forma de escenario, lo cual se logra sobreponiendo los canvas y aplicando z-index

Usa CSS para imagenes de background

cuando se desea usar una imagen de fondo se recomienda usar css para evitar el renderizado de la imagen

Escalar el canvas mendiante CSS transforms

En caso de ser necesario escalar el elemento canvas se recomienda usar css y es preferible escalar un elemento canvas pequeño para hacerlo mas grande que escalar un elemento canvas grande para hacerlo mas pequeño El caso optimo es evitar escalar el elemento canvas 

                
                    const scaleX = window.innerWidth / canvas.width;
                    const scaleY = window.innerHeight / canvas.height;

                    const scaleToFit = Math.min(scaleX, scaleY);
                    const scaleToCover = Math.max(scaleX, scaleY);

                    stage.style.transformOrigin = "0 0"; //scale from top left
                    stage.style.transform = `scale(${scaleToFit})`;

Apagar la transparencia

Si la app no hace uso del backdrop transparente, se recomienda desactivar la propiedad alpha 

                
                    const ctx = canvas.getContext("2d", { alpha: false });

Escalado para altas resoluciones

Cuando un elemento canvas es visualizado en pantallas de alta resolucion es posible que luzca borroso, una de las posibles soluciones es escalar el canvas 

                
                    // Get the DPR and size of the canvas
                    const dpr = window.devicePixelRatio;
                    const rect = canvas.getBoundingClientRect();

                    // Set the "actual" size of the canvas
                    canvas.width = rect.width * dpr;
                    canvas.height = rect.height * dpr;

                    // Scale the context to ensure correct drawing operations
                    ctx.scale(dpr, dpr);

                    // Set the "drawn" size of the canvas
                    canvas.style.width = `${rect.width}px`;
                    canvas.style.height = `${rect.height}px`;
