imagenes

ademas de dibujar paths tambien se pueden usar imagenes y el proceso comprende:

  • obtener una referencia de la imagen desde un HTMLImageElement, un canvas o desde una ubicacion remota
  • dibujar la imagen utilizando la funcion drawImage()

Fuentes de las imagenes

los elementos que se pueden dibujar son los siguientes:

  • HTMLImageElement - utilizando el constructor Image() o a partir de un elemnto img
  • SVGImageElement - imagenes embebidas utilizando image
  • HTMLVideoElement - obteniendo el frame actual de un objeto video
  • HTMLCanvasElement - utilizando otro objeto canvas como imagen

Obtener imagenes de la misma pagina

esto se puede realizar mediante document.images, document.getElementById() o document.getElementsByTagName()

Imagenes de otros dominios

mediante el uso de la propiedad crossorigin HTMLImageElement.crossOrigin se puede solicitar el permiso de uso de una imagen siempre y cuando host permita el acceso cross-domain del recurso.
de no ser asi, el canvas pasaria a ser un tainted canvas (canvas inseguro).

Creando una imagen mediante el constructor Image()

Se debe de pasar la ruta de la imagen y es muy importante usar drawImage() una vez que la imagen ha terminado de cargarse, lo cual se logra con un eventHandler de load

Usando una imagen embebida

tambien se puede utilizar una imagen embebida de la siguiente manera img.src = 'data:image/gif;base64,R0lGODlhCwALAIAAAAAA3pn/ZiH5...';

con este metodo no es necesario esperar la carga de la imagen, pero hay que tener en cuenta que se pierde el uso de la cache y las cadenas pueden ser grandes.

usando frames de un elemento video

Se puede obtener el elemento video y pasarlo a la funcion drawImage();

Slicing

tambien se puede cortar una imagen y posteriormente hacer un posicionamiento y escalar dicha imagen esto se logra con la ultima sobrecarga drawImage(image,sx,xy,swidth,sheight,dx,dy,dwidth,dheight) donde s es prefijo de source y d de destination.
con sx,xy,swidth,sheight vamos a controlar la porcion de imagen que queremos tomar y con dx,dy,dwidth,dheight la posicion y escalado de la imagen resultante

suavizado al escalar iamgenes

cuando se escala una imagen, puede resultar en bordes o detalles difuminados, ya que por defecto se realizar un suavizado por medio de algoritmos con esa finalidad, dado cada contexto se puede desactivar ese comportamiento mediante las siguiente propiedad que por defecto es true: 

                
                    ctx.mozImageSmoothingEnabled = false;
                    ctx.webkitImageSmoothingEnabled = false;
                    ctx.msImageSmoothingEnabled = false;
                    ctx.imageSmoothingEnabled = false;
