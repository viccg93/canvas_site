animaciones basicas

cuando se trata de animaciones en canvas, JS nos es de gran utilidad

limitaciones

la mayor limitacion es que una vaz que una forma se ha dibujado se mantiene en esa posicion, para moverla necesitamos redibujarla y todo lo que se habia dibujado previamente.
esto es algo que puede ser complicado y pesado en terminos de rendimiento cuando se trata de frames complejos y es dependiente del poder del equipo donde se esta ejecutando.

pasos para realizar una animacion basica

  • limpiamos el canvas - a menos que las formas ocupen todo el canvas (backdrop), la manera mas facil es con clearRect()
  • almacenar el estado - para usar el estado original cada vez que un frame se va a dibujar
  • pinta las formas animadas
  • restaurar el estado de canvas

Controlando una animacion

en circunstancias cormales siempre se va a mostrar el canvas una vez que el script ha finalizado, lo cual hace que no sea posible utilizar un for() para controlar la animacion

para controlar la animacion vamos a recurrir a alguno de los siguientes metodos:

  • setTimeout() - ejecuta una funcion pasado x numero de tiempo
  • setInterval() - ejecuta una funcion de manera continua dado un numero de tiempo entre ejecucion
  • requestAnimationFrame(callback) - le indica al navegador que se ejecutara un proceso de repaint que es una animacion
la forma mas optima en la mayoria de los casos es requestAnimationFrame(), pero de no tener interaccion se puede realizar con setInterval() y en caso de tener interaccion, el uso de setTimeout() y addEventListener() pueden ser una buena idea.
