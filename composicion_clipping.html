composicion y clipping

cuando se dibuja una forma, por defecto lo hace por encima de otras formas (en caso de que existan) que coinciden con el espacio de la la forma que se esta dibujando. Este comportamiento por defecto se puede modificar mediante la propiedad 

                    globalCompositeOperation
tambien contamos con la propiedad clip que permite ocultar partes de formas que no queremos que sean visibles 
                    
                        clip

clipping path puede lograr un efecto muy similar a lo que se obtiene con globalCompositeOperation sobre todo en las operacions in, out y atop. con la diferencia de que clipping path no dibuja una figura. una forma de ver el uso de clip() es como una delimitacion de lo que sera visible en el canvas. de esta manera completamos las tres operaciones de cierre: 

                    
                        stroke()
                        fill()
                        clip()
clip() cerrara el path que se dibuje marcando dicho path como una area de clipping.
