manipulacion de pixeles

para acceder a los pixeles de una imagen oregion del canvas, tenemos el objeto ImageData

objeto ImageData

el objeto ImageData tiene los siguientes miembros; 

                    
                        width - ancho de la imagen
                        height - alto de la imagen
                        data - arreglo que almacena valores enteros de 8 bits (0 - 255) que contiene los valores rgba de cada pixel
el campo data contiene un arreglo de eneteros de 8 bits, que almacena los valores de rgba de cada pixel, es decir que las primeras 4 posiciones corresponden a los valores de red, green, blue y alpha del primer pixel iniciando desde la esquina superior izquierda.
de esta manera los valores de rgba del primer pixel estan en data[0], data[1], data[2], data[3]. para recorrer todos los pixeles seria de 4 en 4 posiciones.
El numero de elementos en el arreglo es width * height * 4

metodo para obtener los indices de rgba de un pixel dadas sus cordenadas

                
                    //considerando que las cordenadas inician en 0
                    function getRGBA(x,y,width){
                        let startIndex = (width*4)*y + x*4;
                        return [startIndex,startIndex+1, startIndex+2, startIndex+3];
                    }

guardar imagenes

canvas permite alamacenar el contenido que se ha dibujado, por defecto es en png y con una resolucion de 96 dpi, estos valores pueden ser modifidos. el metodo para generar el uri de la imagen y posteriormente alimentar un elemento img o un link es canvas.toDataURL(), las opciones se muestran acontinuacion: 

                    
                        canvas.toDataURL('image/png'); //default
                        canvas.toDataURL('image/jpeg', quality); //quality es un valor entre 0 y 1 correspondiente a la calidad - 1 es la mejor y 0 la mas baja (mucho menor tamaño)

como alternativa tenemos el metodo canvasToBlob(callback,type,encoderOptions) el cual permite crear un blob para descarga.
