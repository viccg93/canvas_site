A diferencia de SVG, canvas permite solo 2 figuras primitivas; rectangulos y paths (lineas unidas con puntos)

Tenemos tres funciones para rectangulos:

  • fillRect(x,y,width,height) - crea un rectangulo relleno
  • strokeRect(x,y,width,height) - crea el contorno de un rectangulo
  • clearRect(x,y,width,height) - limpia un rectangulo

dibujando paths

un path es un conjunto de puntos unidos por una linea Se crea el path, se usan lso comandos para dibujar en el path y se renderiza los metodos principales son:

  • beginPath()
  • Paths methods
  • closePath()
  • stroke()
  • fill()
Al usar beginPath() se almacenan los paths dibujados y cada vez que se llama se hace reset y se pueden dibujar un nuevo path closePath() cierra la figura entre el primer y ultimo punto, cuando se usa fill() es en automatico, pero necesario con stroke()

Creando un triangulo

moveTo() es una forma de posicionar el puntero sin dibujar, lo equivalente a levantar un lapiz.

lineas

se pueden dibujar lineas con el metodo lineTo(x,y)

arcos

mediante los arcos se pueden generar circulos, semicirculos y lineas curvas mediante:

  • arc(x,y,radio, anguloInicial, anguloFinal, anti-clockwise)
  • arcTo(x1,y1,x2,y2,radio)
El angulo en arc(...) se mide en gradianes, mientras que el metodo arc traza un arco entre 2 puntos de control y un punto inicial.

curvas cuadraticas y curvas Bezier

ambos paths permiten dibujar curvas con una forma organica

las curvas cuadraticas tienen un punto de inicio(punto verde), un punto donde terminan (punto azul) y un punto de control (punto rojo) este ultimo permite modificar el comportamiento de la curva. te debes colocar en el punto de inicio con moveTo() e invocar la funcion quadraticCurveTo(cpx,cpy,x,y) donde: cpx y cpy son las cordenadas del punto de control y las cordenadas del punto donde termina estan dadas por x y y como se muestra a continuacion:

las curvas Bezier son similares a las cuadraticas, con la diferencia de que en lugar de tener un solo punto de control tienen 2. para utilizar este tipo de curva debes de utilizar la funcion bezierCurveTo(cpx1,cpy1,cpx2,cpy2,x,y);

objetos Path2D

los objetos Path2D almacenan los comandos que crean un path para dibujar el paths de una manera mas rapida, simplificando el codigo y mejorando el performance. las instancias de esta clase se realizan mediante los siguientes constructores:

  • new Path2D() - path vacio
  • new Path2D(path) - path creado a partir de otro path existente
  • new Path2D(d) - path creado a partir de un path SVG
todos los metodos de path como lineTo(), arc(), rect(), etc. esta disponibles para los objetos Path2D ademas cuenta con el metodo addPath(path,[transformation matrix]) que permite combinar paths mediante el uso de matrices de transformacion

Path2D con paths SVG

tambien se pueden generar paths pasando una cadena con un path SVG como el siguiente: new Path2D('M10 10 h 80 v 80 h -80 Z')
