Estilos y color

el color por defecto tanto para lineas como relleno es negro, pero se puede cambiar mediante las instracciones 

        
        ctx.fillStyle = "blue";
        ctx.strokeStyle = "blue";

        //los formatos aceptados son los mismos que en CSS

        ctx.fillStyle = 'orange';
        ctx.fillStyle = '#FFA500';
        ctx.fillStyle = 'rgb(255, 165, 0)';
        ctx.fillStyle = 'rgba(255, 165, 0, 1)';

globalAlpha

el atributo globalAlpha del objeto context permite cambiar la transparecia entre 0.0 y 1

rgba()

para definir colores con transparencias se utiliza rgba() que se pasa en forma de cadena a strokeStyle y a fillStyle

estilos de lineas

las siguientes funciones permiten modificar la apariencia de las lineas:

  • lineWidth = value - modifica el grosor
  • lineCap = type - modifica los finales
  • lineJoin = type - modifica la apariencia de las intersecciones
  • miterLimit = modifica el grososr de las intersecciones
  • getLineDash() - agrega un patron de dash
  • setLineDash(segments) - modifica el patron del dash
  • lineDashOffset = value - permite indicar el inicio del patron dash
algo que se debe de tomar en cuenta en el siguiente ejemplo es que la linea de ancho 1.0 (default) en un punto del eje Y toma 0.5 de un pixel y 0.5 del siguiente pixel, sombreando las mitades de pixel que no se rellenaron. para arreglar esta situacion se puede elegir una cordenada con .5 extra para que la linea cubra el pixel completo o en su defecto aumentar el lineWidth.

lineCap

puede recibir 3 valores: butt, round y square butt deja las terminaciones de la linea cortadas en los punto exactos, round agrega un circulo con radio igual a la mitad del grosor de la linea y square agrega una caja con ancho igual al grosor de la linea y con alto igual a la mitad del grosor

lineJoin

puede recibir 3 valores: round, bevel y miter round agrega un circulo en la interseccion dando un efecto redondeado, bevel agrega un triangulo para rellenar el espacio de la interseccion aplanando la interseccion y miter conecta el borde exterior de las terminaciones para formar una punta.

miterLimit

por defecto tiene un valor de 10, este define cual es la distancia maxima ente la parte interna y externa de la interseccion, con angulos amplios la prolongacion que realiza miter es relativamente corta, pero a medida que el angulo formado por la interseccion es mas pequeño, la prolongacion tendra que ser mayor cuando las lineas que conforman la interseccion son casi perpendiculares, la prolongacion para unirlas es casi exponencial, miterLimit permite unir estas lineas como bevel cuando se alcanza el limite con el valor de 10.0 corta las intersecciones con angulos por debajo de los 11 grados.

dashes

getLineDash() retorna el arreglo del patron del dash, mientras que setLineDash(segments) asigna el patron que se utilizara para el dash y lineDashOffset permite definir donde incia el dash en la recta

gradientes

gradiente lineal

se pueden objetos de gradiente lineales a partir de la siguiente funcion ctx.createLinearGradient(x1,y1,x2,y2) posteriormente se utiliza la funcion gradiente.addColorStop(posicion,'color') para agregar un color al gradiente, se pueden agregar el numero de colores que sea necesario.

finalmente el objeto gradiente se asigna a la propiedades de fillStyle o strokeStyle segun sea el caso.

las cordenadas que se le pasan a la funcion representan una linea que podemos entender como la trayectoria del gradiente, ademas estan dadas en funcion del canvas y no del path

gradiente radial

se pueden objetos de gradiente radial a partir de la siguiente funcion ctx.createRadialGradient(x1,y1,r1,x2,y2,r2) y tabien se utiliza la funcion gradiente.addColorStop(posicion,'color') para agregar los colores

con la diferencia de que los valores son de 2 circulos que marcan el inicio y fin del gradiente.

gradiente conico

se pueden objetos de gradiente conico a partir de la siguiente funcion ctx.createConicGradient(startAngle,x,y) y tabien se utiliza la funcion gradiente.addColorStop(posicion,'color') para agregar los colores

el angulo de inicio comienza sobre el centro de manera vertical y continua con direccion clockwise.

patrones

se pueden aplicar patrones que se repiten para el relleno de un path, para ello se pueden utilizar imagenes, videos u otros canvas
para utilizar un patron se utiliza la funcion ctx.createPattern(elemento,tipo de repeticion)
en el parametro de tipo de repeticion se pueden asignar las siguientes cadenas:

  • repeat - repite la imagen en el eje x y en el eje y
  • repeat-x - repite el objeto solo en el eje x
  • repeat-y - repite el objeto solo en el eje y
  • no-repeat - solo agrega el objeto una vez

cabe destacar que la imagen debe de estar totalmente cargada antes de que se aplique el patron

sombreado

se pueden aplicar sombreados a objetos como texto y su comportamiento se modifica con las siguientes propiedades

  • shadowOffsetX = float - distancia horizontal entre el sombreado y el objeto
  • shadowOffsetY = float - distancia vertical entre el sombreado el objeto
  • shadowBlur = float - tamaño del efecto blur, por defecto es 0
  • shadowColor = color - color del sombreado

reglas del relleno

cuando una path se va a rellenar y este comparte espacio o intersecta con otros paths es necesario indicar cual es el espacio que debe ser rellenado, existen dos posibles valores que se pueden pasar al metodo fill('fillRule')

  • 'nonzero' - regla non-zero winding
  • 'evenodd' - regla even-odd winding
